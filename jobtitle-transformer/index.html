A hybrid NLP pipeline that turns messy, multilingual healthcare job titles into one clean, standard taxonomy. Deterministic rules handle the known variants fast and transparently, semantic search catches the long tail, and every row comes back with an explainable result, in its original order.

Key engineering decisions

The choices that make the pipeline accurate, explainable and safe to run on production data.

01

Rules first, ML second

Known variants are resolved by deterministic rules: fast, repeatable and explainable. Machine learning only handles what the rules have never seen.

02

Variants, exact matches, exclusions

Each category combines broad regex variants, a curated exact-match list and explicit exclusions, so recall stays high without false positives.

03

Built from real-world data

Thousands of real spellings, abbreviations and translations across English, French, Spanish, Portuguese, Turkish, Indonesian and more.

04

Clean before you match

HTML entities, accents and stray whitespace are normalised first, so every rule sees consistent text and one pattern covers many encodings.

05

Semantic search for the long tail

Unmatched titles are embedded with Sentence-BERT and matched to the nearest taxonomy label with FAISS, in batches for large datasets.

06

ML results are always visible

Every ML match is flagged as semantic with its distance, an optional threshold rejects weak matches, and review="interactive" asks for confirmation first.

07

Integrity by design

Every input row is tracked end to end. The output always has the same rows, in the same order, with the same index, or an IntegrityError is raised.

08

Shipped like a real library

Versioned on PyPI with a changelog, 52 tests on Python 3.9–3.13, and every release through a pull request with CI checks.

Quickstart

Works with any DataFrame and column name, a Series, a list, or a single title.

pip install jobtitletransformer

import pandas as pd
import JobTitleTransformer as jtt

jtt.normalize_title("Dermatologue")          # 'Dermatologist'

contacts = pd.read_csv("contacts.csv")
clean, report = jtt.normalize(contacts, column="job_title", return_report=True)
print(report)                                # rules / semantic / placeholder / unmatched

Use semantic=False for a fast, fully deterministic run, semantic_threshold=0.8 to reject weak ML matches, or review="interactive" to confirm them.
